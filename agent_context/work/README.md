# Work records

Each task owns one uniquely named Markdown record. Active records are both progress logs and path
claims. Completed records preserve the final evidence without creating one high-conflict shared log.

Filename format:

```text
YYYYMMDD-HHMMZ-<tool-or-owner>-<short-task>.md
```

Use `../templates/work-item.md`. Do not reuse a filename, and do not edit another task's record.
